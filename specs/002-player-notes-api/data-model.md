# Data Model: Player Notes API

**Branch**: `002-player-notes-api` | **Date**: 2026-04-01

---

## Entity: Note

The sole persisted entity. Represents one author's note about one player.

### Fields

| Field | Java Type | DB Column | Constraints | Notes |
|-------|-----------|-----------|-------------|-------|
| `id` | `Long` | `id BIGSERIAL` | PK, auto-increment | Generated by DB |
| `userId` | `Long` | `user_id BIGINT` | not null | Parsed from JWT `sub` claim; immutable after creation |
| `uniqCode` | `String` | `uniq_code VARCHAR(255)` | not null, non-blank | External player identifier; immutable after creation |
| `data` | `String` (raw JSON) | `data JSONB` | not null | Valid JSON object, ≤ 10 KB (UTF-8); stored as JSONB in PostgreSQL |
| `noteTimestamp` | `Long` | `note_timestamp BIGINT` | not null | Unix timestamp (seconds) of creation; set once, never updated |
| `noteEOLTimestamp` | `Long` | `note_eol_timestamp BIGINT` | not null | Unix timestamp (seconds) of expiry; = `noteTimestamp + 2592000`; reset to `now + 2592000` on extend |

> 2592000 = 30 × 24 × 60 × 60 seconds

### JSON Response Shape

```json
{
  "id": 1,
  "userId": 42,
  "uniqCode": "player-abc-123",
  "noteTimestamp": 1743580800,
  "noteEOLTimestamp": 1746172800,
  "data": {
    "rating": 8,
    "comment": "Strong left foot"
  }
}
```

### Validation Rules

- `userId`: derived from JWT `sub` claim as `Long.parseLong(jwt.getSubject())` — JWT validation precedes this
- `uniqCode`: non-null, non-blank → HTTP 422 if blank
- `data`: UTF-8 byte size ≤ 10,240 bytes → HTTP 422 if exceeded; must parse as JSON object
  (`readTree().isObject()`) → HTTP 422 if not; stored as `JSONB` in PostgreSQL
- `noteEOLTimestamp`: an active note satisfies `note_eol_timestamp > currentUnixTime()`

### Derived Concept: Active Note

An **active note** is any row where `note_eol_timestamp > EXTRACT(EPOCH FROM NOW())`.
This is not a stored column — evaluated at query time. The 100-note limit counts active notes only.

### Uniqueness Rule

The pair `(user_id, uniq_code)` MUST be unique across all active notes for a given user.
Enforced at application level: `existsByUserIdAndUniqCodeAndNoteEOLTimestampAfter(userId, uniqCode, now)`.
No DB partial unique index — PostgreSQL does not support volatile predicates in index conditions.
Any unexpected DB integrity violation is caught and mapped to HTTP 409.

## Database Schema (DDL)

```sql
CREATE TABLE notes (
    id                BIGSERIAL    NOT NULL PRIMARY KEY,
    user_id           BIGINT       NOT NULL,
    uniq_code         VARCHAR(255) NOT NULL,
    data              JSONB        NOT NULL,
    note_timestamp    BIGINT       NOT NULL,
    note_eol_timestamp BIGINT      NOT NULL
);

-- Fast lookup of active notes by user, newest first
CREATE INDEX idx_notes_user_active
    ON notes (user_id, note_eol_timestamp DESC, note_timestamp DESC);
```

> **Dev profile (H2)**: `data` column mapped as `TEXT` (H2 does not support JSONB natively).
> Spring Boot profile `prod` uses the above DDL via Flyway migration `V1__create_notes_table.sql`.
> JPA column definition uses `@Column(columnDefinition = "jsonb")` for PostgreSQL;
> overridden to `text` for H2 via profile-specific `orm.xml` or `@Profile`.

## State Transitions

```
[Created] ──────────────────────────────────────────────────────────► [Active]
          noteEOLTimestamp = noteTimestamp + 2592000                   (noteEOLTimestamp > now)

[Active]  ──extend()──► [Active]   noteEOLTimestamp = now + 2592000 (reset)
[Active]  ──delete()──► [Gone]     row permanently removed
[Active]  ──time──────► [Expired]  noteEOLTimestamp ≤ now; invisible to API; pending purge
[Expired] ──cleanup───► [Gone]     row removed by scheduled job
```

## Repository Query Summary

| Operation | Condition |
|-----------|-----------|
| List active notes for user | `user_id = ? AND note_eol_timestamp > ? ORDER BY note_timestamp DESC` |
| Count active notes for user | `user_id = ? AND note_eol_timestamp > ?` |
| Find active note by id + user | `id = ? AND user_id = ? AND note_eol_timestamp > ?` |
| Check duplicate (user + uniqCode) | `EXISTS WHERE user_id = ? AND uniq_code = ? AND note_eol_timestamp > ?` |
| Delete one (active, owned) | `DELETE WHERE id = ? AND user_id = ? AND note_eol_timestamp > ?` |
| Delete all active by user | `DELETE WHERE user_id = ? AND note_eol_timestamp > ?` |
| Cleanup purge | `DELETE WHERE note_eol_timestamp < ?` |
