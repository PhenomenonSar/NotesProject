# Data Model: Player Notes API

**Branch**: `002-player-notes-api` | **Date**: 2026-04-01

---

## Entity: Note

The sole persisted entity. Represents one author's note about one player.

### Fields

| Field | Java Type | DB Column | Constraints | Notes |
|-------|-----------|-----------|-------------|-------|
| `id` | `UUID` | `id UUID` | PK, not null | Generated by the service |
| `authorId` | `String` | `author_id VARCHAR(255)` | not null | JWT `sub` claim — immutable after creation |
| `uniqCode` | `String` | `uniq_code VARCHAR(255)` | not null, non-blank | External player identifier — immutable after creation |
| `content` | `String` | `content TEXT` | not null | Valid JSON object, ≤ 10 KB (UTF-8) |
| `createdAt` | `Instant` | `created_at TIMESTAMPTZ` | not null | Set on creation, never updated |
| `updatedAt` | `Instant` | `updated_at TIMESTAMPTZ` | not null | Set on creation, updated on content change |
| `expiresAt` | `Instant` | `expires_at TIMESTAMPTZ` | not null | `createdAt + 30 days`; reset to `now + 30 days` on extend |

### Validation Rules

- `authorId`: non-null, non-blank (derived from JWT — service responsibility to validate token first)
- `uniqCode`: non-null, non-blank (rejected with HTTP 422 if blank)
- `content`: must be a valid JSON object (`{...}`); arrays, primitives, null → HTTP 422; UTF-8 byte
  size must be ≤ 10,240 bytes → HTTP 422 if exceeded
- `expiresAt`: always `> now` for active notes; notes with `expiresAt ≤ now` are treated as
  non-existent by all API operations

### Derived Concept: Active Note

An **active note** is any row where `expires_at > NOW()`. This is not a stored field — it is
evaluated at query time. The 100-note limit counts active notes only.

### Uniqueness Rule

The pair `(author_id, uniq_code)` MUST be unique across all active notes for a given author.
- Enforced at application level: check `existsByAuthorIdAndUniqCodeAndExpiresAtAfter(now)` before
  insert.
- A DB-level unique constraint on `(author_id, uniq_code)` is NOT applicable because uniqueness
  is scoped to active notes (time-based), and PostgreSQL partial indexes do not support volatile
  predicates. Any unexpected DB integrity violation is caught and mapped to HTTP 409.

## Database Schema (DDL)

```sql
CREATE TABLE notes (
    id          UUID                     NOT NULL PRIMARY KEY,
    author_id   VARCHAR(255)             NOT NULL,
    uniq_code   VARCHAR(255)             NOT NULL,
    content     TEXT                     NOT NULL,
    created_at  TIMESTAMP WITH TIME ZONE NOT NULL,
    updated_at  TIMESTAMP WITH TIME ZONE NOT NULL,
    expires_at  TIMESTAMP WITH TIME ZONE NOT NULL
);

-- Index: fast lookup of active notes by author, newest first
CREATE INDEX idx_notes_author_active
    ON notes (author_id, expires_at DESC, created_at DESC);
```

> **Dev profile**: Schema managed by `spring.jpa.hibernate.ddl-auto=create-drop` (H2).
> **Prod profile**: Schema managed by Flyway migration `V1__create_notes_table.sql`.

## State Transitions

```
[Created] ──────────────────────────────────────────────────────► [Active]
              expiresAt = createdAt + 30d                          (expiresAt > now)

[Active]  ──extend()──► [Active]   expiresAt = now + 30d (reset)
[Active]  ──delete()──► [Gone]     row permanently removed
[Active]  ──time──────► [Expired]  expiresAt ≤ now; invisible to API; purged by cleanup job
[Expired] ──cleanup───► [Gone]     row permanently removed by scheduled job
```

## Repository Query Summary

| Operation | Query |
|-----------|-------|
| List active notes for author | `WHERE author_id = ? AND expires_at > ? ORDER BY created_at DESC` |
| Count active notes for author | `WHERE author_id = ? AND expires_at > ?` |
| Find active note by id + author | `WHERE id = ? AND author_id = ? AND expires_at > ?` |
| Check duplicate (author + uniqCode) | `EXISTS WHERE author_id = ? AND uniq_code = ? AND expires_at > ?` |
| Delete one by id + author (active) | `DELETE WHERE id = ? AND author_id = ? AND expires_at > ?` |
| Delete all active by author | `DELETE WHERE author_id = ? AND expires_at > ?` |
| Cleanup purge | `DELETE WHERE expires_at < ?` |
